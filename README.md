# מתכנן התואר – הנדסת חשמל, טכניון

**לפתיחה:** https://orisela1234.github.io/technion-ee-degree-planner/

כלי לתכנון התואר במסלול הנדסת חשמל (004004-1-000), לפי קטלוג תשפ"ו 2025/2026.

## איך משתמשים
1. פותחים את הקישור.
2. גוררים למסך הפתיחה את קובץ ה-PDF של **תעודת הציונים** מהטכניון.
3. המערכת בונה לבד את תרשים התואר לפי סמסטרים. משם אפשר:
   - לגרור קורסים בין סמסטרים, עם בדיקת קדמים;
   - לבחור שרשראות (קבוצות התמחות) ולשייך קורס משותף לשרשרת אחת;
   - לערוך ציונים ולסמן עובר בינארי;
   - לסווג את קיזוז המילואים;
   - לראות בלשונית "סגירת תואר" אם כל התנאים מתקיימים.
4. כשמגיע גיליון ציונים חדש מעלים אותו בלשונית "גיליון ציונים". התכנון שלכם נשמר.

## פרטיות
- הקובץ נקרא **רק בדפדפן שלכם**. שום דבר לא נשלח לשרת, ואין שרת בכלל.
- הנתונים נשמרים בדפדפן (localStorage), כך שלכל אחד יש את התכנון שלו בנפרד.
- מספר תעודת הזהות לא נשמר.
- למעבר למחשב אחר: ⚙ → "ייצוא גיבוי", ובמחשב החדש "ייבוא גיבוי".

## מה נבדק בסגירת התואר
- **נקודות:** 157.5 נק"ז; חובה 106 (כולל 3 נק' מעבדות מהרשימה); בחירה פקולטית 39.5; כלל-טכניונית 12, מתוכן מל"ג 6 וספורט 2.
- **שרשראות:** לפחות 3 קבוצות התמחות שלמות, וכל קורס נספר בשרשרת אחת בלבד.
- **ממוצע:** ממוצע מצטבר 65 ומעלה (תקנה 3.2.1).
- **אנגלית:** שני קורסים באנגלית (תקנה 1.3.3).
- **לומדה:** הלומדה למניעת הטרדות מיניות.
- **ספורט:** עד 1.5 נק' בסמסטר.
- **פקולטות אחרות:** עד 9 נק' מפקולטות אחרות.
- **מגבלות נוספות:** עובר בינארי, וקיזוז מילואים עד 10 נק'.

> כלי עזר בלבד. ההחלטה על זכאות לתואר היא של מזכירות לימודי הסמכה בפקולטה.

## פיתוח
```bash
npm install
npm run dev       # שרת פיתוח
npm run data      # רענון נתוני הקורסים מ-CheeseFork
npm run release   # בונה קובץ HTML יחיד ל-site/index.html
```
האתר מוגש מהענף `gh-pages`, שמכיל קובץ HTML יחיד.
